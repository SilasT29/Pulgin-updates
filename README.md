# PluginUpdater

Ein einfacher Minecraft Plugin Updater mit GUI.  
Das Programm durchsucht einen ausgewählten Ordner nach Plugins, verschiebt diese automatisch in einen eigenen `plugins`-Ordner und prüft anschließend auf verfügbare Updates.

## ⚠️ Aktueller Status

Dieses Projekt befindet sich aktuell noch in einer frühen Entwicklungsphase.

### Bereits funktionsfähig
- GUI vorhanden
- Ordnerauswahl funktioniert
- Link-/Webseitenfunktionen funktionieren
- Automatisches Erstellen des `plugins`-Ordners

### Noch nicht funktionsfähig
- Update-Prüfung der Plugins
- Automatisches Herunterladen von Updates
- Plugin-Erkennung ist noch unvollständig
- Versionsvergleich noch in Entwicklung

---

## Funktionen

- Moderne GUI
- Einfach per Drag & Drop nutzbar
- Erstellt automatisch einen `plugins`-Ordner
- Verschiebt erkannte Plugins automatisch
- Geplante Update-Prüfung über Modrinth

---

## Nutzung

1. Programm herunterladen
